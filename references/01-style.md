# 01 · 风格手册

这一页是「一模一样」的全部依据。动画面可以自由，但这几组数字不要凭感觉改。

## 配色

```ts
// src/lib/theme.ts
paper      #F7EFDD   米白纸底，占画面 60% 以上
paperDeep  #EFE3C9   次级纸片（叠在纸底上时用）
ink        #161616   墨黑：所有描边、正文、硬阴影
inkSoft    #4A4030   说明文字、次要标签
yellow     #FFC53D   品牌黄：高亮块、片尾整屏
yellowSoft #FFE28A   浅黄：只在纸底上用（黄底上会糊）
orange     #FF7A1A   强调动作/数字/箭头
red        #E8412C   警示、印章、痛点
blue       #2E6BE6   只用于地图/信息类贴纸，全片占比 <10%
teal       #17B0A0   备用，基本不用
white      #FFFFFF   贴纸底、手机边框
```

三条配色纪律：

1. **一屏最多两个强调色**。黄 + 墨是默认；要强调动作时加橙；要制造不安时才用红。
2. **黄底上不要用浅黄**（`yellowSoft` 会糊成一片），要压深就用 `#EDA318`。
3. **蓝和青是信息色，不是品牌色**，出现面积一旦超过画面 10%，整套视觉就散了。

## 字体

```ts
display  "PF"     微软雅黑 / PingFang 子集，400 / 500 / 600
hand     "HAND"   楷体，只用于手写注解
```

所有字都经 `scripts/fonts.py` 子集化到 `public/fonts/*.woff2`。**改了文案必须重跑 `npm run fonts`**，否则新字会回退成系统字体、字重断掉。

### 字号层级（1920×1080 下的实测值）

| 用途 | 字号 | 字重 | 字距 | 备注 |
|---|---|---|---|---|
| 主标题（第二行/最大） | 136 | 700 | −5 | 用 `Hl` 加黄块 |
| 主标题（第一行） | 104 | 700 | −3 | 行高 1.2 |
| 次级标题 | 92 | 700 | −3 | 与主标题同屏时降一档 |
| 卡片大数字 | 132–146 | 700 | −4 | `tabular-nums` 防跳动 |
| 片尾品牌名 | 152 | 700 | +10 | 正字距，撑住整屏 |
| 片尾定位语 | 56 | 700 | +2 | |
| 贴纸正文 | 34–38 | 700 | +0.5 | |
| 段首小标签 | 26 | 600 | +6 | 颜色 `#8A7A5C`，如「实 测 数 据」 |
| 手写注解 | 40–42 | 400 | 0 | `FONT.hand`，配 `rotate(-1.5deg)` |

**标题永远不换行**：给 `whiteSpace: "nowrap"`。宁可减字号，也不让第二行掉下来。

## 纸张质感（三层，缺一层就变「纯色块」）

```tsx
<PaperBg dots="tr" />   // 纸底 + 颗粒 + 半调网点 + 暗角
```

1. **颗粒**：SVG `feTurbulence` 生成，`opacity .3`，`mixBlendMode: multiply`，平铺 260×260。
2. **半调网点**：`radial-gradient(ink 3.4px, transparent 3.6px)`，网格 24×24，不透明度 .16，
   直径 620px 的圆贴在一个角上（`dots="tl|tr|bl|br"`）。**一屏只放一个角**。
3. **暗角**：`radial-gradient(120% 90% at 50% 45%, transparent 55%, rgba(120,96,50,.10))`。

## 撕纸边

```ts
torn("top" | "bottom", seed)   // 26 段折线，振幅 = sin 项 4.2 + cos 项 2.2（%）≈ 6.4%
```

- 用**确定性伪随机**（`seed` 参与 sin/cos 的相位），不是 `Math.random()`——同一个 seed 每帧一致，不会抖。
- 一个 `TornBand` 只有一侧是撕的，另一侧是直边并伸出画面外。要上下都撕，叠两条。
- `TornBand` 高度 232–252px 时最像纸带；小于 120px 会像锯齿条。

## 贴纸语法

| 元素 | 参数 |
|---|---|
| 白贴纸 | `border 6px ink` + `radius 16` + `shadow(8)` + `rotate −4°…+3°` |
| 深色贴纸（台词） | `color ink / text yellow`，`border 5px`，`shadow(8)` |
| 手机框 | `border 9px white` + `outline 6px ink` + `shadow(14)` + `radius 34` |
| 印章 | `border 6px red` + `mixBlendMode: multiply` + `rotate −8°…−9°` + 落定时从 1.35 缩到 1.0 |
| 高亮块 | `Hl`：黄块高 0.52em，左右各溢出 8–10px，`rotate(-1deg)` |
| 手绘箭头 | `strokeWidth 9`，`strokeLinecap round`，曲线 `M10 24 C 92 2, 168 46, 190 118` |

**旋转只允许 ±5°**，超过就像掉在地上的贴纸，不像贴上去的。

## 动效语言

| 动作 | 用法 | 参数 |
|---|---|---|
| 纸片弹入 | 所有贴纸/卡片进场 | `ramp(t,[a,a+0.26],[0,1],EASE.back)` + `translateY(50→0)` + `scale(0.9→1)` |
| 标题入场 | 逐行，间隔 0.4s | `EASE.back`，`translateY(46→0)` |
| 数字滚动 | 价格、币数、时长 | `Counter`，`dur 0.9`，`EASE.out` |
| 印章落定 | 数字停稳后 0.15s | `scale(1.4→1)` 落 + `mixBlendMode multiply` |
| 重拍冲击 | 场景切点 | `impulse(t, at, 3.4)` → `scale(1+0.02)`；`shake(t,[at], 8, 9)` |
| 焦点推近 | 截图信息太小 | `Phone` 的 `zoom 1.4–2.2` + `fx/fy` |
| 场景切换 | 全程 | 直接硬切，靠撕纸/纸张色差过渡，**不要淡入淡出叠化** |

缓动只用四个：

```ts
EASE.out   (0.16,1,0.3,1)     出场、数字
EASE.back  (0.34,1.56,0.64,1) 弹入（带过冲）
EASE.inOut (0.87,0,0.13,1)    位移
EASE.in    (0.7,0,0.84,0)     退场
```

## 反面清单（出现任何一个，风格就崩了）

- 深色科技感 / 霓虹渐变 / 玻璃拟态 / 发光
- 圆角卡片三等分堆叠（那是 SaaS 落地页，不是拼贴）
- 阴影用模糊（`box-shadow: 0 8px 24px`）——**只用硬阴影 `Npx Npx 0`**
- 描边粗细不统一（有的 4px 有的 8px）
- 截图裸贴（没有手机框/纸片托底）
- 贴纸之间叠压超过 15%，或压住正文
- 同一屏出现两种手写体
