# 02 · 分镜节奏

120 BPM 下，一小节 = 2.0 秒。**60 秒 = 30 小节**，这是整套结构的地基。
所有场景边界都是 2.0 的整数倍，所以任意一次切镜都落在拍子上，不需要转场特效去遮。

## 骨架：钩子 → 品牌 → 证明 → 片尾

```
0s ──────── 6s ── 8s ────────────────────────── 52s ── 56s ──── 60s
   钩子 3 小节   品牌 1 小节      证明 22 小节          我的 2 小节  片尾 2 小节
   （痛点）    （重拍进场）      （一个功能一段，2–8 小节）           （落定）
```

**6.0 秒必须进鼓。** 前三小节只有铺底，制造「憋着」的感觉；第 3 小节线上鼓一进，
品牌整屏揭开——这是全片第一个高能点。**开场不要超过 6 秒**，超过就会泄气。

## 60 秒模板（可直接套）

| # | 起止 | 小节 | 任务 | 屏幕上是什么 |
|---|---|---|---|---|
| 1 | 0–6 | 3 | **钩子**：把观众的麻烦摆出来 | 实景/空镜 + 三张问题纸条 + 一句大白话结论 |
| 2 | 6–8 | 1 | **品牌**：整屏黄 + 角色 + 名字 + 一句定位 | 只有一个 lockup，别加任何别的元素 |
| 3 | 8–14 | 3 | **会答**：问一句就能得到答案 | 手机贴纸 ×1–2 + 一条对话推近 |
| 4 | 14–22 | 4 | **能办事（高潮）**：一句话把事办完 | 台词贴纸 + 数字滚动 + 印章 |
| 5 | 22–28 | 3 | **账户**：签到/余额/明细 | 两屏交替 + 小角标 |
| 6 | 28–34 | 3 | **算得清**：勾选、合计、确认 | 收据式纸卡 + 真实弹窗 |
| 7 | 34–40 | 3 | **到园**：码、券、扫码 | 两张手机并排 + 一券一码贴纸 |
| 8 | 40–46 | 3 | **兜底功能**：失物/工单 | 列表 + 表单（要能看到"自动填好"） |
| 9 | 46–52 | 3 | **数据**：三个可核实的数字 | 三张数字卡连打 + 出处小字 |
| 10 | 52–56 | 2 | **我的**：所有东西在一处 | 汇总页 + 手写注解 |
| 11 | 56–60 | 2 | **片尾**：撕纸收拢，片名落定 | 鸭头 + 片名 + 定位 + 深色标语条 |

### 裁到 45 秒

砍 #5（账户并入 #6）和 #10（我的）；#4 高潮从 4 小节压到 3 小节。**#1、#2、#4、#11 一秒都不能少。**

### 裁到 30 秒

只留 #1（2 小节）、#2（1 小节）、#4（3 小节）、#6（3 小节）、#11（2 小节）= 11 小节，
剩下的用一次快切蒙太奇补（8 张真实截图，每张 0.5 拍）。

## 每段内部怎么排

一段 2–4 小节里，**信息密度按 0.5 拍递进**：

```
第 0.0 拍   段首小标签（26px，字距 6）
第 0.5 拍   第一行标题
第 1.0 拍   第二行标题（带高亮块）
第 1.5 拍   第一个证据（贴纸 / 卡片 / 截图）
第 2.0 拍   第二个证据
第 2.5 拍   结论贴纸 / 印章（落在这一小节的重拍上）
```

对应 `timing.json` 的 `pace`：

```json
{ "pop": 0.26, "step": 0.5, "hold": 0.8 }
```

`pop` = 单张纸片的入场时长；`step` = 相邻纸片的间隔；`hold` = 最后一张停住多久再切。
**画面代码和 `scripts/mix.py` 读的是同一组参数**，改节奏时两边自动同步。

## 卡点怎么定（从音乐反推）

```bash
python3 scripts/music.py analyze audio-src/music.mp3
```

会给出 `bpm / beat / bar / consistency`，以及每个小节的能量峰值。然后：

1. `bar ≈ 2.0s` 才能套这套结构；不是 120BPM 就把 `timing.json` 的 `beat/bar` 改成实测值，
   但**场景边界仍按整数小节算**。
2. 找到**鼓组进入**的那一秒（通常是第 2–4 小节），`drop = 该时刻 − musicOffset`，
   向上取到最近的小节线。品牌镜头就放在 `drop`。
3. `musicOffset` = 曲子第一个小节重音在源文件里的秒数。取太早会带进一段空白，
   取太晚会切掉第一个重音。前奏太长就从**爆发前 1–2 小节**切入，不要让观众等。
4. 片尾最后 1.5s 做指数淡出（`fade_out_exp`），否则收尾会有一下「咔」。

## 讲人话的三条

- **开头用一句大白话说清「这是什么、发生了什么」**，再制造悬念。谜语式开场对不了解背景的人等于没说。
- **屏幕大字和旁白/字幕说同一件事的两面**，不各说各的。
- 交付前做**外行复述测试**：只看屏幕大字，能不能讲出「这是什么 → 凭什么 → 结果 → 我现在能干什么」。
  讲不出来就改字幕，不是改画面。
